MyDoc 0.1.1 新增 Word、表格、PDF、演示文稿和纯文本文件的在线协同编辑，并提供应用内更新、团队通知与服务器全局空间管理。从 0.1.0 升级时数据库自动增量迁移，原有文档、账号和团队空间保持不变。

## 主要更新

- **办公文件协作**：工作区内可直接新建或导入 DOCX、XLSX / CSV / TSV、PDF、PPTX 和 TXT，多人实时编辑，显示成员位置与选区，可导出为原格式。
- **Word**：页眉页脚（左/中/右三栏，支持页码、总页数和首页不同），修订模式（记录插入与删除，可逐处或全部接受/拒绝），表格行列插删、合并单元格，打印预览。
- **表格**：88 个常用函数（数学统计、条件统计、逻辑、查找引用、文本、日期时间），条件格式（规则、色阶、数据条），柱形 / 条形 / 折线 / 饼图 / 面积图，单元格格式、数字与日期格式、合并单元格。
- **PDF**：标准表单填写，批注与讨论，支持中文的导出与扁平化。
- **演示文稿**：对象编辑、母版与版式继承、幻灯片缩略图。
- **评论与通知**：所有办公文件支持评论线程、回复和解决；@提及与回复会出现在通知铃铛中，可跳转到对应位置。
- **版本与导出**：命名版本、版本比较与原位恢复；导出任务在后台排队，服务重启后自动继续。
- **文档概览**：全部文档的列表 / 网格视图，支持收藏和标签筛选；图片可双击预览。
- **应用内更新**：桌面端可从 GitHub Release 或自托管服务器检查、下载并重启安装新版本。
- **服务器管理**：服务器管理员可查看和管理所有团队空间，相关操作记录在审计日志中。

## 升级说明

- 0.1.0 不支持应用内更新，请下载本版本安装包覆盖安装。之后的版本可在“版本与更新”中直接升级。
- 启动时自动完成数据库迁移，迁移前生成快照；迁移失败会整体回滚并停止启动，不会改动原数据。
- 升级后的数据库无法再由 0.1.0 打开。如需回退，请使用升级前快照或备份。
- 自托管服务器请使用 `mydoc-web:0.1.1` 镜像，保留原数据目录挂载，不要开启 `MYDOC_INIT_DATABASE`。

## 下载与安装

- Apple 芯片 Mac：`MyDoc-0.1.1-mac-arm64.dmg`。
- Intel Mac：`MyDoc-0.1.1-mac-x64.dmg`。
- Windows x64：`MyDoc-0.1.1-win-x64.exe`。
- macOS 最低版本为 13.0。`SHA256SUMS.txt` 提供发布附件的 SHA-256 校验值；ZIP、`latest*.yml` 和 `.blockmap` 用于应用内更新。

## 当前限制

- 安装包尚未完成正式证书签名与 Apple 公证。macOS 应用内安装依赖有效签名，未签名包可能需要手动下载安装。
- Windows 安装运行及 Intel Mac 实机验证仍待完成。
- 办公文件不承诺与 Microsoft Office 完全一致：Word 分页为按浏览器排版估算，不支持复杂 Excel 函数、PPT 动画及任意改写 PDF 原文。
- Web 服务完全不可达时，新编辑内容仅保留在页面内存中，关闭页面前请导出草稿。
