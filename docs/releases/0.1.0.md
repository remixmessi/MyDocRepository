MyDoc 0.1.0 是首个初始版本，将 Markdown 文档、无限白板和知识管理整合到同一个工作空间，提供 Web、自托管服务和 macOS / Windows 桌面入口。

## 主要功能

- **文档编辑**：Markdown 快捷输入与源码模式、表格、代码高亮、任务列表、标注框、LaTeX 公式和 Mermaid 图表。
- **无限白板**：图形、连线、手绘、思维导图、图片与富文本笔记，支持分组、图层、画框和 PNG 导出。
- **知识连接**：文档提及、双向链接、文档嵌入、白板引用和实时标题大纲。
- **内容管理**：多工作区、嵌套文件夹、彩色标签、收藏、集合、模板、日记和回收站。
- **搜索与导航**：全文搜索、页内查找、统一命令面板、多标签页与分屏。
- **导入与导出**：Markdown / Notion、文件夹及 ZIP 导入，Markdown / HTML / PDF 导出和工作区备份恢复。
- **团队协作**：自托管账号、工作空间、成员邀请、角色管理、实时编辑与共享附件。
- **桌面集成**：文件关联、拖放导入、`mydoc://` 深链、远程服务器连接，以及 GitHub / 自托管服务器手动版本检查。

## 数据与备份

使用 SQLite 保存数据，支持自动整库快照、恢复预览和恢复前保护备份。启动时检查数据库结构与完整性，按版本增量迁移；升级失败回滚并停止启动。附件采用独立文件存储，支持历史数据迁移和备份恢复。

## 下载与安装

- Apple 芯片 Mac：`MyDoc-0.1.0-mac-arm64.dmg`。
- Intel Mac：`MyDoc-0.1.0-mac-x64.dmg`。
- Windows x64：`MyDoc-0.1.0-win-x64.exe`。
- macOS 最低版本为 13.0。`SHA256SUMS.txt` 提供发布附件的 SHA-256 校验值。

## 当前限制

- 项目仍在持续开发，本流程提供开发安装包，尚未完成正式证书签名与 Apple 公证，自动更新渠道未启用。
- Windows 安装运行及 Intel Mac 实机验证仍待完成。
- 团队成员可阅读空间内全部文档，文档授权目前主要控制编辑权限。
- Web 服务完全不可达时，新编辑内容仅保留在页面内存中，关闭页面前请导出草稿。
