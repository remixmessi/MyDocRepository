本清单用于后续 Codex 分批实施。范围为当前项目的工作空间管理、Web 服务端同步、多人协作和桌面远程接入，参考 AFFiNE 的能力与交互。已完成项表示当前实现和已有验证，不表示与 AFFiNE 全功能等价，也不代表生产环境验收完成。

## 执行约束

- 按批次顺序推进；每批完成实现、必要验证和文档更新后，再勾选对应任务。
- 使用项目 SQLite／桌面 SQLite 持久化，不引入浏览器 localStorage、IndexedDB 等作为业务持久存储。
- 已有数据库启动时复用；新数据库只初始化空结构，不携带测试用户、示例文档或其他人的内容。
- 保留现有本地文档和附件，数据库结构变更必须有版本迁移与失败保护。
- 服务端执行权限校验，覆盖文档、白板、附件、同步及管理接口，不能仅依赖界面禁用。
- 测试使用独立数据库；外部邮件发送、公开分享发布、正式部署和 CI 运行单独按实际授权执行。
- 移动端暂不推进；发布渠道暂不配置。

## 第 1 批：草稿恢复与 SQLite 持久队列

目标：先让已有草稿可恢复，再解决离线改动关闭页面后丢失的问题。

- [x] 明确离线能力边界：浏览器不能直接写项目 SQLite；Web 服务仍可达但同步链路失败时，可由服务端 SQLite 暂存；服务端完全不可达时，普通浏览器缺少本地持久写入通道，需要桌面 SQLite／本地代理才能满足禁止浏览器持久化的约束。
- [x] 设计队列表、草稿表、迁移版本及账户／服务器／工作空间隔离键。
- [x] 支持工作空间与单文档 `.mydoc-draft.json` 导入，校验格式、版本、大小及 Yjs 数据。
- [x] 提供恢复预览：文档标题、正文摘要、白板内容、附件缺失提示。
- [x] 支持恢复为个人工作区中的新文档；权限恢复后另行选择是否合并回原文档（当前仅支持恢复为新文档，合并回原文档未实现）。
- [x] 被删除或失去权限的文档只恢复为新副本，不能绕过 tombstone 或重新授予访问权。
- [x] 有 SQLite 写入通道时，先落盘更新再进入发送队列；收到服务端确认后才清理已确认条目。
- [x] 重启后加载待提交更新，保证重复提交幂等、提交顺序可恢复。
- [x] 记录重试次数与失败原因，采用退避重试并支持手动重试。
- [x] 登录过期、降权、成员移除时暂停队列，保留草稿，不转投其他账户或工作空间。
- [x] 显示待提交数量、最后成功同步时间及明确的关闭页面提示。
- [ ] 验证断网、进程退出、重启、重复提交、账号切换、权限撤销、永久删除和损坏草稿。

验收：有本地 SQLite 通道的客户端在完全断网后编辑、退出、重启仍能恢复；Web 的可达与不可达场景分别说明并测试，不将内存保存标记为持久保存。

本次验证：真实 SQLite／HTTP 队列测试覆盖原子写入回滚、关闭再打开数据库、客户端重建、重复确认、确认丢失后的幂等重放、自动退避、账户隔离及 401／403／410 暂停；草稿解析同时限制文件总大小、单个 Yjs 更新大小和累计 Yjs 数据预算。浏览器验证同步提交失败后刷新恢复、手动重试、空间删除后读取暂存草稿恢复为个人副本；原有双账户协作、断网后保持页面重连、降权与成员移除回归通过。不等同于桌面断网后真实进程退出／重启验收，第 53 项及整批最终验收仍未完成。
