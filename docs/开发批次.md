# 开发批次与验收记录

## 批次 01 · 本地段落编辑闭环（2026-09-30）

目标：从空仓库建立可运行 Web 应用，先完成一种块从模型到编辑到存储的完整链路。

已落地：
- Yarn 4 workspaces，common/crdt、common/nbstore、editor/framework、editor/blocks、frontend/core、frontend/apps/web 分层。
- 块以 Y.Map 表示，子节点顺序为 Y.Array；提供 addBlock/updateBlock/deleteBlock/moveBlock，校验重复 ID、schema、父块、索引和根块约束。
- root → paragraph；块 schema 注册表，不包含完整 DI 或命令扩展系统。
- ProseMirror + y-prosemirror 将段落内容绑定至 Y.XmlFragment；加粗、斜体与段内换行；共享 Y.UndoManager。
- DocumentStorage 平台接口与 IndexedDB 实现，readwrite 事务合并 Yjs 更新，避免不同存储实例互相覆盖。
- 工作区目录独立 Y.Doc；单工作区文档创建、切换、重命名、确认删除。
- 加载、空内容、禁用、存储失败和重试，桌面/窄屏布局。

参考项目（只读参考，未修改）：
- `../AFFiNE/package.json`：workspace 分层。
- `../AFFiNE/blocksuite/framework/store/src/model/store/crud.ts`：块 schema 校验与块操作分离。
- `../AFFiNE/blocksuite/affine/ext-loader/src/store-manager.ts`：模型扩展与视图扩展分离思路。
- `../AFFiNE/packages/common/nbstore/src/storage/doc.ts`：二进制存储接口与更新合并。

实现取舍：第一批使用自有 IndexedDB 适配器而非 y-indexeddb，便于暴露事务提交状态、错误和重试，且后续 SQLite 可复用二进制接口。当前每次更新事务会合并已有二进制，较大文档的增量日志/快照压缩留到后续批次。

限制：
- 块树只有根块与段落，不支持 note 容器或内容块嵌套。
- Enter 为段内换行；跨块拆分、合并、Tab 缩进安排在批次 02。
- CRDT 更新可合并，并发重排/删除的树一致性和在线广播尚未实现，不标记同步引擎完成。
- 文档目录与文档内容是两个存储记录，尚无跨记录原子提交；失败保留内存状态并提供重试，异常中断可能留下不可见的孤立文档记录。
- 离线编辑指已加载应用内的本地编辑，不包含 Service Worker 离线冷启动。

- 删除空间前列出文档数、附件数、存储量与受影响成员数，并要求输入工作空间名称；唯一成员时提示无法转移所有权，只能删除。
- 成员与邀请每 8 秒刷新，操作完成后立即重载，避免按过期权限展示可用操作。
- 侧边栏保存文案按当前工作区区分「团队工作空间：服务端数据库」与「个人工作区：本机／项目 SQLite」。
- 验证：类型检查、生产前端与独立服务构建、58 个单元测试文件共 234 项（新增 `tests/cloud-settings.test.ts` 3 项覆盖概览统计、邀请生命周期、管理员越权与查看者限制），本机 Google Chrome 两个端到端用例通过。
- 尚未验收：20 人以上长列表分页、所有权转移与退出空间确认、删除空间名称校验仅有代码与单元层面覆盖，未做端到端人工验收。第 2 批整体验收不勾选。

### 工作空间第 3 批：账户设置与会话管理

- 协作表按需扩列：账户增加头像、头像类型、邮箱验证状态与注册时间；会话增加公开 ID、登录时间、最近活动、UA 与 IP；新增一次性口令表。启动逐列检查后 `ALTER TABLE`，已有库只补缺失列。
- 账户设置页集中维护显示名称、头像、邮箱验证、修改密码、更改邮箱与登录设备。头像限制 256 KiB 与 PNG／JPEG／WebP，按文件魔数校验，失败不破坏已有头像。
- 改密校验当前密码，默认让其他设备重新登录，当前会话换发新 token 后继续可用；密码重置清空该账户全部会话。
- 登录设备列表展示设备、IP、登录与最近活动时间，只暴露会话公开 ID，可注销指定会话或其他全部会话，被注销设备立即断开实时连接。
- 邮件服务由环境变量配置，内置极简 SMTP 客户端（EHLO／STARTTLS／AUTH LOGIN），不支持 STARTTLS 时拒绝明文发送凭据。未配置时如实上报原因：验证与更改邮箱的口令回传给已验明身份的本人，找回密码的口令只写服务端日志。
- 一次性口令只存哈希，重发即替换旧口令，使用后删除，过期单独报错。找回密码对存在与不存在的邮箱返回完全相同的响应。
- 更改邮箱先验证新地址再写入；发往旧地址的未接受邀请失效，更改前后都报告受影响数量。找回密码、验证、更改邮箱按 IP 与用途分别限频。
- 会话到期与失去权限分开处理：401 时状态区提示登录已过期、页面内容与已暂存草稿仍保留，提供重新登录入口，重新登录后继续重放待提交队列。
- 验证：类型检查、生产前端与独立服务构建、59 个单元测试文件共 244 项（新增 `tests/cloud-account.test.ts` 10 项，含本地假 SMTP 服务器），本机 Google Chrome 三个端到端用例通过（新增 `tests/e2e/account.spec.ts`）。测试不向真实地址发信。
- 尚未验收：OAuth 等其他登录方式按清单约定不在本批实现；真实 SMTP 服务商投递与邮件客户端渲染未做实际验收。第 3 批整体验收不勾选。
