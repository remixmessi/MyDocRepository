## 开发

建议 Node.js 22 LTS，Corepack + Yarn 4。

```sh
corepack yarn install --immutable
corepack yarn dev
```

```sh
corepack yarn typecheck
corepack yarn test
corepack yarn build
corepack yarn exec playwright install chromium
corepack yarn test:e2e
```

## 文档编辑

正文为单一 ProseMirror 编辑区域，不提供独立段落模块、添加段落按钮、块菜单或拖动手柄。新建后直接输入，支持跨行选择、整篇全选、删除、撤销、重做。点击正文空白可定位，回车自然续写。

- 输入 `#`～`######` 加空格生成标题，`>` 加空格生成引用。
- 输入 `- ` 或 `1. ` 生成列表；列表内输入 `[ ] ` / `[x] ` 生成待办。Tab / Shift+Tab 缩进与反缩进。
- 支持 `**加粗**`、`*斜体*`、反引号行内代码、`~~删除线~~`、Markdown 链接。
- 三个反引号加语言名后回车进入代码；在代码末尾另起一行输入三个反引号并回车退出。Ctrl/⌘ + Enter 也可退出代码。
- 代码块顶部可搜索选择语言、复制代码、折叠/展开和添加本地评论；更多菜单可切换自动换行/行号、复制定位链接、复制块或删除。显示设置与评论自动保存，结构操作可撤销。语言列表提供纯文本及 SQL、JS/TS、HTML/CSS、JSON、Python、Shell、Java、C/C++/C#、Go、Rust、YAML、Markdown 的高亮。
- `---` 后回车生成分隔线。
- 纯文本剪贴板按 Markdown 解析整篇内容，支持标题、列表、任务、引用、代码、图片网址、链接和表格。
- 标注框：`/callout` 插入，可切换信息、提示、重要、警告、注意五种样式，正文直接编辑；Ctrl / ⌘ + Enter 退出到框外，“转为正文”保留内容。Markdown 使用 `> [!NOTE]` / TIP / IMPORTANT / WARNING / CAUTION，可键入标记后按 Enter、粘贴或导入，支持嵌套与历史。
- 数学公式：`/math` 或 `/latex` 选择行内/块公式，点击“编辑公式”输入 LaTeX，实时预览，应用或取消；Ctrl / ⌘ + Enter 应用。支持 `$x^2$` 行内、独立 `$$` 围栏或 math/latex 代码围栏；独立 `$$` 后 Enter 新建块公式。行内公式须非空、单行，美元字符须转义；编辑时自动去除首尾空白。语法错误保留源码，允许再次编辑修正。
- Mermaid：`/mermaid` 插入图表，或导入/粘贴 Mermaid 代码围栏；键入独立的 Mermaid 开围栏后 Enter 创建空图表。编辑源码实时预览，应用、取消与错误反馈，支持流程图和时序图等；图库按需加载，源码保存在本机，SVG 为临时预览。首次加载可见绘制状态。
- 三种能力共用于正文、白板富文本笔记及内部文档只读预览，支持保存/刷新、撤销、Markdown 和完整备份；标注框内引用纳入双向链接，公式和图表源码纳入检索。Markdown 表格内提供行内公式，块公式、图表和标注框通过菜单在表格外插入。
- 输入 `/` 打开格式菜单，支持中文/英文搜索、上下方向键、Enter、Escape 与鼠标选择；可转换文本、六级标题、列表、待办、引用、代码或插入分隔线与表格。代码内的 `/` 保留原文。
- 正文输入 `[[` 搜索并引用当前工作区的其他文档；也可点击顶部“插入引用”。支持方向键、Enter、Escape 与鼠标选择，代码内不触发。引用随目标重命名更新，目标删除后保留正文并显示失效状态。
- 顶部“大纲”显示 1–6 级标题，内容实时更新，点击可滚动定位并继续输入；同名标题按位置区分。
- 文档底部“双向链接”可展开查看来源文档、引用次数与正文摘要，以及本文引用的目标；点击可跳转。引用索引随编辑更新，启动时从本地数据重建。
- 正文上方“上传图片 / 添加附件”，或 `/image`、`/attachment` 选择本地文件；支持 PNG、JPEG、GIF、WebP 图片、任意附件，单文件最多 20 MB，每次最多 10 个。也可粘贴图片或拖入文件，代码内不插入文件。图片直接显示，附件提供文件名、大小与下载；刷新后从 IndexedDB 读取。
- “添加书签 / 嵌入网页”或 `/bookmark`、`/embed` 插入网页卡片。填写网址，可尝试读取标题与摘要，也可手动填写；卡片支持编辑、删除、书签与嵌入互换及历史撤销。嵌入点击“加载网页”后连接网站，可停止加载，或通过“打开网页”访问原页面。
- “嵌入文档”或 `/embed-doc` 选择当前工作区的其他文档，正文显示随原文档更新的只读预览。支持打开原文档、更换、折叠、移除和撤销；嵌入计入双向链接，目标删除后保留位置并提示。
- 顶部“页面 / 白板”切换同一文档的两种视图。白板提供选择、平移、矩形、椭圆、菱形、三角形、六边形、星形、箭头、圆角矩形与文本工具；拖动创建、移动，右下角调整大小，也可在属性栏编辑文字、填充与尺寸，复制或删除。滚轮平移，Ctrl / ⌘ + 滚轮缩放；支持适应内容、键盘微移和撤销重做。
- 文本元素创建后直接进入画布内编辑；文本和所有普通图形可双击、选择后按 Enter 或点击“编辑文字”进入。Enter 换行，Escape / Ctrl 或 ⌘ + Enter / “完成文字编辑”结束；支持文本选择、中文组合输入与撤销重做，连续输入按时间窗口合并历史。编辑浮层随画布缩放与位置变化同步，长内容内部滚动，每个元素最多 2,000 个字符；超限保留已保存内容。
- “连线”从图形或空白处拖动到目标，蓝框提示吸附；端点随图形移动和尺寸变化更新。选择连接线后可拖动圆形端点重连，或在属性栏指定起点/终点，调整箭头、颜色、粗细。删除图形会把相关端点留在原位置，撤销恢复锚定；移动或复制整条线会解除锚定。
- 连接线支持直线、折线、曲线及同目标自环，折线可启用近邻障碍避让；可拖动/输入路径控制点，编辑标签、虚线和双端三角/开放箭头/圆/菱形标记。选择普通图形后可向四个方向“新增并连接”。
- 图形文字可设置字号、颜色、粗体、斜体、对齐和自动撑高；Markdown 模式显示加粗、斜体、行内代码、删除线与链接文字。边框可设置颜色、粗细及虚线，文本仍以 Markdown 源文输入。
- “手绘”可先选择颜色与粗细，按住拖动绘制，松开保存整条笔画，连续绘制无需重新选择工具。选择工具可按笔迹选中、移动和缩放；Escape 取消当前笔画。每条最多 2,000 个采样点；支持曲线平滑、触笔压感、荧光笔，橡皮擦可删除整条笔画或切除局部路径，取消不写入，松开一次提交。
- 选择工具在空白处拖动框选完整包含的元素，Shift 点击追加或移出选择，Shift 拖动追加框选；也可使用“全选元素 / 加入选择”。多选支持整体拖动、键盘移动、复制和删除，一次撤销恢复整批操作。
- “分组 / 取消分组”将所选成员作为整体操作，点击任一成员选择整个组；画布聚焦时 Ctrl / ⌘ + A 全选，Ctrl / ⌘ + G 分组，Ctrl / ⌘ + Shift + G 取消分组。复制会重映射内部连线和组关系；外部锚点转为自由端点。多选或整组可拖动共同边界右下角手柄缩放，Shift 保持比例，Escape 取消；也可输入组合宽高后点击“应用组合尺寸”。缩放以共同左上角为基准，统一限制成员最小尺寸，松开一次提交并支持撤销。内部锚点跟随，外部锚点保留；手绘路径同步调整，文本/笔记字号与笔画粗细保持。含导图的组合强制等比，导图内部布局与文字同步缩放（0.1–4 倍），折叠和换父级继续可用。多选含画框会同时缩放其完整内容，单独调整画框仍仅改变边界。尺寸及组关系随保存、刷新和备份保留；支持最多 16 层嵌套：已有组与其他同层成员再次分组会保留子组。选择一个完整组后点击“进入分组”、Enter 或双击组成员逐层进入，组内选择/移动/缩放/复制/删除限定当前层，单成员可直接编辑；“返回上级”或 Escape 逐层退出。取消分组只拆当前所选一层，保留子组；组内新建元素归入当前组，复制重建内部所有组 ID，删除后自动清理不足两个实际成员的组。层级保存到本机、历史和完整备份；可通过目标分组面板移动，或按 Ctrl / ⌘ 拖入目标组成员；完整组保留内部层级，校验锁定、循环和深度。分组内不创建画框。
- 白板“图片”上传本地 PNG/JPEG/GIF/WebP，支持画布聚焦后粘贴及拖入文件（落点居中）；单张最多 20 MB，每次最多 10 张。正文已有的本地图片可通过选择器复用；图片属性可改名称、下载原文件或插入正文末尾，文件数据共享。图片支持移动、等比缩放、连接锚点、分组/图层/画框、复制删除和撤销恢复，含图片组合强制等比。仅视口附近挂载图片，离屏释放对象 URL；缺失或读取失败可重试。完整备份包含仅白板引用的文件，正文与复制元素的共享文件去重。
- 大白板使用共享空间索引裁剪绘制和精确点选，连接线锚点通过 ID 映射查找；拖动每个动画帧合并最新位置，松手前处理最终位置。笔记仅挂载视口附近的内容，正在编辑的笔记移出视口仍保留；图层列表按窗口显示，聚焦列表后支持方向键、Home/End。最多 5,000 个元素的限制不变。开发环境可执行 `node scripts/benchmark-whiteboard.mjs` 复测稀疏场景，记录见 `artifacts/batch05-performance-comparison.json`；密集场景支持共享图片解码、增量索引及细节降级，纯 Canvas 批次达到 200 元素时启用 Worker 渲染和有界位图缓存；过期帧丢弃，不支持 Worker/OffscreenCanvas 时回退主线程。含图片或笔记的混合批次沿用主线程图层。
- “置顶 / 置底 / 上移一层 / 下移一层”调整所选元素的绘制和点选顺序；多选或分组保持内部相对顺序，图层列表按从上到下显示并支持选择。排序随本地保存、撤销和完整备份保留；画框始终位于内容背景层。
- “画框”工具拖动创建，或通过“为所选创建画框”包围选中内容。可编辑名称、背景和尺寸，拖动边框/标题携带当前完整包含的元素（整组需全部在框内），复制画框同时复制这些内容。调整边界不缩放成员，删除画框保留内容；画框之间不建立嵌套关系，不裁剪框外元素。
- “思维导图”工具点击创建中心主题，点击主题或使用主题下拉选择后编辑文字，添加子主题/同级主题、删除整个分支。按子树大小自动排列，可切换向左/向右/双侧布局；画布聚焦时 Tab 添加子主题、Enter 添加同级主题。拖动中心主题或按 Alt 拖动移动整张导图，支持复制、删除、图层和画框操作，以及历史、主题全文搜索、保存与完整备份。每张最多 200 个主题、50 层，每主题最多 200 字；尚无主题画布内直接编辑。
- 思维导图主题上的“− / +数量”按钮或属性栏“折叠分支 / 展开分支”控制后代显示，隐藏主题保留搜索和备份，主题下拉只列可见节点；选中主题隐藏时回到可见祖先。双侧布局按一级分支顺序左右交替，后代沿所属侧展开；给折叠主题添加子主题会展开路径。布局与折叠更新导图边界及整体连接线锚点，支持历史、刷新、备份和画布引用预览。
- 非中心主题拖到同一导图的其他主题上，松开后携带整条子树换父级；目标高亮并显示提示，禁止自身/后代及超过 50 层。空白释放不修改，Escape 取消并保留选择；折叠目标自动展开到移动分支。属性栏“父主题”也可操作，适合键盘与窄屏。一次撤销恢复整个分支；中心主题、Alt 拖动或多选仍整体移动。支持同级前移/后移及跨导图完整子树移动，可选择目标图/父主题或直接拖入；中心主题不能跨图，松开单事务提交，取消保留原树。
- “文档卡片”选择当前工作区的其他文档，插入标题与最多 500 字的正文摘要，可切换成紧凑文档链接、更换目标、复制文档链接，通过双击、画布聚焦时 Enter 或“打开原文档”跳转。目标标题与摘要同步刷新，删除目标保留卡片并提示，读取失败可重试。卡片支持连接线锚定、尺寸/背景、移动、分组、图层、画框及历史；引用纳入双向链接和标题搜索，完整备份恢复重映射目标。摘要不展开图片、附件或嵌套预览，编辑请打开原文档。
- “笔记”在视口中心创建并进入画布内编辑，支持标题、列表、待办、引用、代码块、表格、加粗/斜体、Markdown 输入与粘贴以及 `/` 格式菜单。双击、画布聚焦时 Enter 或“编辑笔记”进入编辑，“完成编辑”或 Escape 退出；编辑时适应当前笔记，长内容内部滚动。笔记支持宽高/背景、移动、分组、图层、画框、锚定连接、独立复制、共享撤销重做、全文搜索与完整备份恢复，页面正文保持独立。每篇最多 20,000 个 Markdown 字符；暂不支持笔记内图片、附件、文档嵌入或字符级多人协作。
- “引用画布”或正文 `/surface-ref` 选择当前工作区的文档与画框（支持同文档），显示按画框裁剪的实时只读预览。可折叠、更换、移除、撤销，通过“打开原白板”定位画框；删除目标保留引用并提示。引用参与双向链接，完整备份恢复重映射目标，窄屏按比例缩放。也可拖选任意矩形区域，或输入位置/尺寸；区域随目标实时更新，并定位原白板。预览保持只读。
- 图片选择后可拖动旋转手柄（Shift 吸附 15°）或输入角度；“裁剪图片”支持原图拖选、百分比范围、取消和恢复完整图片，原文件保留。旋转后命中、锚点、缩放、画框引用与 PNG 采用同一几何。
- “排列与吸附”提供六向对齐、水平/垂直等距分布；分组视为整体。可开启 24 世界像素网格吸附和对象边缘/中心吸附，辅助线提示目标，Alt 临时关闭。
- “分组树与图层管理”可逐层展开、选择、命名、锁定和隐藏图层/分组。祖先组锁定及隐藏作用于全部成员，组内新成员继承组设置；锁定阻止编辑和变换，管理面板可解锁。
- “画框导航与演示”支持定位、前后排序、全屏演示、方向键/PageUp/PageDown/Home/End 翻页和 Escape 退出；浏览器不允许全屏时使用演示视图。
- “导出 PNG”可选择全部可见内容、当前所选或指定画框，支持透明背景及 1/2/4 倍；最长边上限 4096 像素。导出包含图片和笔记静态文字；笔记采用 Canvas 排版，复杂富文本样式不保证与 DOM 预览像素一致。
- 缩放低于 35% 或可见图片/笔记超过 100 时启用轻量 Canvas 显示，编辑中的笔记保留；轻量图像资源最多同时加载 32 种，其余显示名称占位。图片共享文件读取、解码和对象 URL，卸载释放；空间索引按变化元素及关联连接线增量更新。密集拖动测量见 `artifacts/batch05-dense-performance.json`，复测运行 `corepack yarn test:e2e tests/e2e/whiteboard-complete.spec.ts --workers=1 -g 5000`。

- “白板模板”内置流程图、双侧导图及规划布局。所选元素可保存为本文模板（最多 20 个，每个 250 元素），支持删除/撤销和带图片 JSON 导入导出；完整备份收集仅模板引用的图片，导入会重建元素/组/图片资源标识。
- 白板元素自动保存到本机，文字纳入全文搜索，完整工作区备份保留白板。Markdown 导出只包含页面正文；视图和缩放为临时状态，重新进入白板自动适应内容。
- 标题下方“文档选项”中的“Markdown 源码”可直接编辑源码；“编辑”返回排版界面，“导出 Markdown”下载 `.md` 文件。
- 表格通过 `/` 菜单、粘贴或源码输入生成，支持列对齐、直接编辑和 Tab 单元格导航。

块链接只在保存了相应文档的浏览器中有效；评论目前为本机评论，尚无多人讨论或身份系统。代码块显示设置与评论保存在本地文档数据中，不写入标准 Markdown 导出。

正文持久化为一个 Y.XmlFragment。旧版块数据自动迁移，原块树保留为兼容备份；迁移不会进入用户撤销历史。普通正文仍有 Markdown 语义节点，但不再是独立 UI 模块。

支持多个本地工作区，IndexedDB 存储。清除站点数据会清除文档；建议使用完整工作区备份保留正文与本地文件。暂无云同步、SQLite 或原生应用。白板使用 Canvas 2D、空间索引和可回退的 Worker 位图渲染；当前本地白板 TODO 已完成，GPU 引擎和云端多人协作属于后续架构路线。Markdown 源码模式与导出使用规范化序列化，不保留所有原始空行或分隔符风格；支持本地图片与附件，也继续支持图片网址。复杂表格合并单元格不属于 Markdown 表格范围。

## 文档组织、检索与备份

- 侧边栏工作区选择器切换独立本地工作区，旁边的“工作区选项”提供新建、重命名与确认删除。旧数据继续保留在“本地工作区”。
- 文件夹按钮创建嵌套文件夹，通过文件夹行的“管理”入口重命名或调整上级；文档顶部的文件夹选择器调整归属。删除文件夹保留其中的文档与子文件夹并移至上级。
- “搜索与命令”或 Ctrl/⌘ + K 打开统一命令面板，支持当前工作区中文、标题/正文/标签搜索、摘要预览与键盘选择。正文改动会增量更新，启动时从本地文档重建索引。
- “工作区选项 → 导入 Markdown / 导入 Notion”打开预览确认流程，支持文件、文件夹和带资源 ZIP；详细说明见下方导入章节。
- “备份工作区”下载 `.mydoc.json`，包含文件夹、文档完整 Yjs 数据、正文引用的本地文件及代码显示设置和评论；“恢复备份”校验后创建新工作区，不覆盖已有工作区。恢复文件最多 50 MB；内部页面引用会映射到恢复后的新文档。
- Markdown 导出适合交换正文；工作区备份用于保留完整本地数据。备份恢复暂不保留本次会话的撤销栈，全文索引会重建。

本地文件以 `asset:` 标识写入 Markdown，单独的 `.md` 不包含文件二进制；跨浏览器迁移请使用工作区备份。文件从正文或白板移除后仍保留本机数据以支持撤销，删除整个工作区会清理对应文件；暂未提供未引用文件清理、正文图片尺寸调整与附件内嵌预览。

书签与网页嵌入的元信息以 `mydoc-web-card` JSON 代码围栏保存到 Markdown，源码往返与工作区备份会保留卡片；其他 Markdown 工具会显示该围栏内容。网页信息读取受 CORS 限制，没有跨域代理；网页嵌入受网站自身策略限制，不支持所有网站。网络失败可手动填写，嵌入失败可打开原页面。

输入 `@` 打开当前工作区文档搜索，可输入中文或含空格的标题，方向键选择、Enter 插入、Escape 关闭，也可点击候选；`[[` 和工具栏插入引用继续可用。触发位置为行首、空白或常见标点之后，邮箱/网址、代码块、行内代码和中文组合输入期间不弹菜单；空结果保留原文。提及复用已有引用节点，支持点击跳转、目标重命名与删除提示、撤销重做、Markdown 往返、全文搜索和双向链接。白板笔记编辑/预览共用，笔记与模板中的引用在工作区恢复时重映射到新文档。

页面引用以标准 Markdown 链接保存工作区与文档标识；链接需要对应浏览器本地数据。选择器与反向链接索引限定当前工作区，正文与白板富文本笔记支持 `@` 文档提及；跨工作区全局反向索引和云端共享尚未实现。

内部文档嵌入以 `mydoc-embed-doc` JSON 围栏保存。完整备份恢复会重映射目标文档 ID；单独导出 Markdown 不携带目标文档。预览最多 250 个节点、10,000 个文字字符，支持本地图片；附件请打开原文档下载，嵌套嵌入显示跳转入口，避免循环展开。

画布引用以 `mydoc-surface-ref` JSON 围栏保存工作区、文档与画框标识或区域边界；单独 Markdown 不携带目标白板，跨浏览器迁移使用完整备份。预览显示图形、连线、手绘、导图和笔记，白板文档卡片显示链接提示，不递归展开嵌入。

验收与后续计划见 [开发批次](docs/开发批次.md)。

表达内容使用 KaTeX 与 Mermaid 渲染。单公式最多 10,000 字符、图表最多 20,000 字符；白板笔记仍受整篇 20,000 字符限制。图表配置指令不开放，使用固定安全配置和净化 SVG，超出边数限制或语法有误时可修正源码重试。既有普通 Mermaid 代码块保留原数据，可通过 Markdown 源码应用或导入转换为图表。白板 PNG 沿用静态笔记排版，公式和图表输出源码文字，不等同于页面预览。

## 标签、收藏与集合

- 侧栏“管理标签与集合”创建、重命名或删除标签；文档顶部“标签与集合”绑定多标签和手动集合，标题下显示已保存的标签。
- 星标按钮收藏/取消文档；侧栏“收藏”、标签和集合筛选可组合，空结果可清除筛选，不影响当前文档继续编辑。
- 集合管理提供手动选择文档，或按规则自动归集。规则可选标签全部/任一、标题或正文包含关键词、已收藏/未收藏，多个条件同时满足，至少设置一个条件。
- 删除规则使用的标签会暂停该集合；检查并重新保存规则后恢复。删除标签或集合保留文档正文；文档删除会清理集合成员。
- 搜索支持标签名称检索、标签过滤及仅收藏。标签、收藏、集合自动存入当前浏览器，工作区备份包含这些关系，恢复时重映射 ID；旧备份兼容。组织操作的保存状态显示在工作区状态栏，失败可重试；组织元数据不进入正文撤销栈。

## 多标签页与分屏

- 侧栏或搜索打开文档到当前活动侧；重复打开切回已有标签，标签标题随重命名更新。方向键、Home/End 切换标签，关闭先保存正文并保留文档。关闭全部标签后可从侧栏重新打开。
- 工作台“左右分屏”或“在另一侧打开”将当前文档打开到另一侧；两侧可同时编辑不同文档，或同步编辑同一文档，也可一侧正文、一侧白板。调整分屏比例，点击编辑区或“左侧/右侧”切换活动侧；“合并分屏”合并并去重标签。
- 文档顶部“引用打开位置”选择本侧新标签或另一侧，适用于正文引用、嵌入、画布引用、双向链接及白板文档跳转。跨工作区目标仍切换整个工作区。
- 每个工作区自动保存标签、当前文档、页面/白板模式、分屏比例和活动侧，刷新恢复；删除文档会清理两侧失效标签。窄屏只显示并挂载活动侧内容，保留左右切换。
- 布局是本机工作区偏好，不包含在文档备份中；关闭标签不进入正文撤销栈。弹窗草稿、光标选区和画布临时视图不作为恢复内容。

## 回收站与恢复

- 删除文档会移入当前工作区的“回收站”，从文档列表、搜索、集合结果及工作台标签中移出。侧栏显示回收数量，可按标题查找并只读预览正文和白板。
- “恢复文档”保留原文档 ID、正文、白板、附件、收藏、仍存在的标签及手动集合绑定；引用与嵌入重新生效。原文件夹被删除时随文件夹删除规则移到上级，失效组织关系不会重新创建。
- “彻底删除”需单独确认，清除该文档的本地数据。附件可能被其他文档使用，因此保留工作区文件；删除整个工作区会统一清理文件。
- 完整工作区备份包含回收文档和附件，恢复为新工作区时重新映射文档及组织关系。旧备份仍可恢复；回收站不自动清空。预览仅为摘要，恢复后可编辑完整内容及下载附件。


## 文档模板

- 侧栏“文档模板”打开模板库，内置会议记录、项目计划、知识笔记。选择模板并填写标题/文件夹，从模板新建独立文档。
- 文档工具栏“保存为模板”保存当前正文和完整白板快照，包括代码设置/评论、画布元素、本文白板模板及引用的附件；以后修改原文档或副本不会改变模板。文件夹、标签、收藏、集合及工作台布局不作为模板内容。
- 自定义模板支持按名称搜索、正文/白板只读摘要预览、重命名及确认删除。删除模板保留已创建的文档与附件。原文档移入回收站或彻底删除后仍可从模板新建。
- “导出文档模板”下载带本地文件的 `.文档模板.json`，“导入文档模板”支持跨工作区迁移；导入重新分配模板和文件 ID，同名自动加后缀。模板中指向原文档自身的正文/嵌入/画布引用及白板笔记/卡片改为新文档；其他文档引用保留原目标，迁移时需要对应目标工作区仍存在。
- 完整工作区备份包含自定义文档模板及其引用的文件，恢复时重映射当前工作区引用；旧备份继续兼容。内置模板无需备份，每个工作区最多 100 个自定义模板，名称/新文档标题最多 160 字，导入导出文件最多 50 MB。
- 模板保存与管理自动持久化，失败保留原状态并提示重试；模板操作不进入正文撤销栈。附件采取保守保留规则，删除整个工作区才统一清理；暂不支持直接编辑模板内容，需要从模板新建、编辑后另存新模板。


## 页内查找

- 在页面正文按 `⌘/Ctrl + F`，或“文档选项 → 页内查找”，打开正文顶部的查找栏。默认忽略大小写，可勾选“区分大小写”。匹配内容高亮，当前项用更深颜色显示。
- Enter / Shift + Enter 或上下按钮循环切换，显示当前序号与数量；无结果时显示“无匹配”。Escape 或关闭按钮清除高亮并恢复正文编辑焦点。重复快捷键会聚焦并选中查找输入；打开时可用正文选中文字作为查询。
- 查找覆盖标题块、段落、列表、标注框、表格单元格与代码正文，支持跨加粗/斜体格式文字、中文及 emoji。查询按字面匹配，正则符号不会作为表达式执行；不跨段落/单元格或行内原子节点匹配。
- 正文编辑、撤销重做及同文档同步更新会刷新结果；跳转不改变文档选区、内容、撤销栈或备份。含匹配的折叠代码临时完整显示，关闭后恢复原折叠状态。
- 分屏只在活动侧查找，切到另一侧会清除原侧高亮；切换文档、页面/白板模式或刷新不会持久化查找栏。手机端输入和操作换行，不产生横向溢出。
- 每次查询最多 256 字符，最多显示并导航 5,000 个匹配，更多时数量显示 `5000+`。查找范围为当前正文文字，不含文档主标题、白板、图片/附件元信息、引用标签和嵌入预览；Markdown 源码模式沿用浏览器原生查找。

## PDF / HTML 导出

- 在“文档选项 → 导出 PDF / HTML”打开静态预览，选择 A4 / Letter、纵向 / 横向、12 / 20 / 25 mm 页边距及是否包含主标题。导出使用打开弹窗时的当前正文快照；分屏导出只包含操作侧文档。
- “下载 HTML”生成可独立打开的只读文件；“打印 / 保存 PDF”打开浏览器打印对话框，选择“另存为 PDF”。最终分页以打印对话框为准，可在那里调整页眉页脚与背景打印。
- 保留标题、列表、待办、标注框、表格、代码高亮/行号、公式与 Mermaid 静态图。代码完整展开并换行，长表格跨页重复表头；查找高亮、编辑工具和本地评论不进入导出。
- HTML 内嵌本地图片、可下载附件和公式字体，可离线阅读；远程图片仍需网络。内部文档嵌入及画布引用导出为原文链接，不递归复制目标正文；网页嵌入转为静态链接卡片。原文链接需要对应本地工作区数据。
- 缺失或损坏本地文件会阻止导出并允许重试，表达式错误保留源码并提示。HTML 最大 50 MB；源码有解析错误时先修正再导出。PDF 展示附件入口，但不把附件二进制嵌进 PDF。
- 导出范围为页面正文，白板图形使用白板 PNG 导出。HTML/PDF 用于阅读和分享，完整迁移仍使用工作区备份。

## PDF 附件预览

- 使用“添加附件”上传 PDF，在附件卡片点击“预览 PDF”，直接阅读本地文件。文件名、PDF MIME 或文件签名均可识别；其他附件继续下载原文件。
- 阅读弹窗支持上一页/下一页、输入页码后 Enter 跳转、适合宽度及 50%～200% 缩放；“下载原文件”保留原始字节，“新窗口打开”使用浏览器 PDF 阅读器。Escape/关闭返回正文编辑。
- 加密 PDF 可输入密码，错误后重新输入；密码仅用于本次打开，不持久化。损坏/缺失文件和页面错误有重试入口，缺失附件可恢复带文件工作区备份。
- 阅读器打开时才加载，按当前页渲染，快速操作取消旧任务，关闭释放解析与渲染资源。手机工具栏换行，默认适合宽度，放大后在页面区域滚动；当前不提供文本选择/搜索、批注或 PDF 编辑。
- 沿用本地文件存储和既有 20MB 单文件上限，无外部阅读服务；刷新、文档模板和工作区备份保留原附件。预览页码、缩放与密码不写入正文或撤销历史。

## 统一命令面板

- 侧栏“搜索与命令”或 `⌘/Ctrl + K` 打开；输入关键词同时搜索文档与命令，输入 `>` 仅搜索命令。标签与收藏筛选只作用于文档，`>` 模式下禁用这两个筛选。
- 包含新建文档、从模板新建、保存为模板、切换到页面/白板、在另一侧打开、合并分屏、收藏/取消收藏、页内查找、PDF/HTML 或 Markdown 导出、回收站、标签与集合管理、Markdown / Notion 导入。
- ↑/↓ 循环选择并跳过不可用命令，Home/End 定位首尾可用项，Enter 执行，Escape 关闭并恢复焦点。重复 `⌘/Ctrl + K` 聚焦并选中查询；输入法组合期间不执行键盘命令。其他弹窗打开时不抢占快捷键。
- 文档跳转、新建、模式切换、查找及导出作用于活动侧；“在另一侧打开”切换到另一侧。没有文档、当前已是目标模式或处于白板时，相应命令禁用并显示原因。查找/导出遇到无效 Markdown 源码时提示先修正源码。
- 默认文档按最近打开排序，命令按最近成功使用排序；最多保存 20 条混合历史，按工作区保留并支持刷新。最近使用属于本机工作区 UI 偏好，不进入文档正文、撤销历史或完整备份。
- 执行中避免重复操作；失败保留面板并提示，收藏保存失败回退原状态，存储恢复后可以再次执行。搜索最多显示 40 篇文档、查询最多 256 字符；暂不提供自定义命令、快捷键重绑定或跨工作区统一检索。


## Markdown 与 Notion 导入

- 工作区选项提供“导入 Markdown”和“导入 Notion”，命令面板也可搜索“导入”。可直接将单个或多个文件、ZIP 拖入弹窗拖放区，也可选择文件或整个文件夹；随后检查文档列表、资源警告和层级，勾选需要的页面，再点击“开始导入”。确认前不写入工作区。
- 普通模式支持 UTF-8 `.md`、`.markdown`、`.txt`，文件名作为标题；Notion 请选择 **Markdown & CSV** 导出包，可读取 ZIP、嵌套分卷 ZIP 或解压后的文件夹，移除页面名与文件夹名末尾的 Notion UUID。CSV 创建普通表格，保留引号、逗号和单元格换行；不恢复数据库视图、属性类型、关系或公式计算，HTML 导出包不在支持范围内。
- 可选择目标文件夹、保留原层级或平铺。成功导入的相对页面链接转换为内部文档引用；Notion 原站链接在包内有唯一对应页面时也可转换。未选/失败页面和缺失资源保留文字与警告，代码内的链接文字保持原样。
- 本地 PNG/JPEG/GIF/WebP 图片和链接附件存入现有本地文件库，支持刷新、下载、PDF 附件预览与完整备份恢复；不支持的图片格式转为附件。仅保存正文引用的资源；远程地址保持原链接，不下载到文件库。`.txt` 属于可导入页面，链接到包内 `.txt` 会成为文档引用。
- 默认按来源类型、相对路径及内容指纹跳过重复导入，也可选择“创建新副本”。文档与引用资源内容变化会重新导入；同名文档保持独立，已有正文不会被覆盖。来源记录随完整备份恢复；资源缺失或链接未完成的页面不标记为可跳过，修复导出包后可再次导入。
- 每批最多 100 篇，输入文件合计 50 MB，解压总量 200 MB、2000 条目；单篇文本 10 MB、单资源 20 MB，ZIP 内单文件 50 MB，嵌套最多两层。CSV 最多 5000 数据行、100 列、50000 单元格。不安全路径、重复路径、损坏 ZIP 和非 UTF-8 文本会明确反馈。
- 导入显示进度和逐页结果；“停止导入”在当前页结束后停止后续页面，成功项保留。存储失败不覆盖已有内容，可完成/关闭后重新选择文件重试，已完整导入的页面默认跳过。


## 正文选区工具栏与编辑器设置

- 桌面选中文字显示浮动工具栏：加粗、斜体、删除线、行内代码、链接和清除格式。混合格式选区统一应用，已全部应用时再次点击取消；支持表格单元格文本，代码块及非文字节点不显示。
- `Alt + F10` 从正文进入工具栏，左右方向键切换按钮，Enter 操作，Escape 返回正文。格式修改进入原有撤销/重做历史并沿用 Markdown 导出、搜索及本地保存。
- 链接弹窗保留原选区，可应用、修改、移除或取消；接受 HTTP、HTTPS 与 mailto 地址，错误输入保留原文。链接编辑期间选区随文档变化映射，关闭恢复正文焦点。
- “文档选项 → 编辑器设置”提供标准/宽/全宽正文、14/16/18/20 px 字号、1.5/1.8/2/2.2 行高、桌面及移动工具栏开关；预览字号和行距，保存、取消与恢复默认。保存失败回退原设置并支持重试。
- 设置按当前工作区保存并同步显示到各文档/分屏，刷新保留，其他工作区独立；属于本机 UI 偏好，不进入正文撤销、Markdown 或完整备份。字号/行高作用于正文常规文字，标题和代码沿用原有排版。
- 手机端工具栏位于可视区域底部，可在光标处切换后续文字的格式；随视口和软键盘空间调整。中文组合输入、源码模式、代码块、其他弹窗及非活动分屏隐藏工具栏。手机链接操作需要先选中文字。


## 脚注

- 正文输入 `/footnote` 或 `/脚注`，也可用“文档选项 → 插入脚注”。填写 Markdown 说明或引用已有脚注；选中文字后添加会保留原文。代码与脚注说明内不提供嵌套插入。
- 上标按第一次出现的顺序自动编号，同一说明可多次引用。点击上标跳转到文末说明，使用“返回正文”及后续返回按钮回到各处引用；分屏在当前侧跳转。
- 文末说明可直接编辑文字，也可点击“编辑脚注”编辑 Markdown。删除脚注同时移除该说明与所有引用，支持撤销/重做、刷新保存、检索与完整备份恢复；缺少说明的上标可点击补充。
- 导入、粘贴与源码使用标准 `[^source]` 和 `[^source]: 资料内容`；多段内容缩进四个空格。未定义引用保持文字，未引用说明保留；重复定义保留为带后缀的独立说明，首次定义接收原标识的引用；`^[行内说明]` 规范化为标准定义。代码里的同形文字保持代码。
- HTML 导出保留编号与双向锚点；PDF 沿用文末说明，不按每页页脚排版。嵌入文档预览显示脚注编号及说明，完整编辑与跳转请打开原文档。每篇最多 500 个说明、5000 处引用；标识最多 160 字符；弹窗单条说明最多 20000 字符。


## 正文行内评论

- 选中正文文字，通过选区工具栏的“评论”、正文上方的“添加正文评论”或 `⌘/Ctrl + Alt + M` 添加；新评论不会替换原文。空选区、代码块及输入法组合期间禁用，选区最多 20000 字符。
- 点击正文浅黄色高亮打开相关评论；重叠范围会选中所有相关评论。点击“评论 (数量)”打开侧栏，筛选未解决、已解决或全部；“定位原文”选择并滚动到当前侧的原文。手机和分屏采用正文下方的评论面板，打开时滚动到面板。
- 本地用户可编辑首条评论、添加/编辑/删除回复，解决或重新打开评论；解决后收起正文高亮。删除整条评论需在面板确认，可通过文档撤销/重做恢复。每篇最多 500 条评论，每条最多 100 条消息，每条消息最多 4000 字符。
- 锚点跟随正文插入、删除与格式变化；原文完全删除时保留评论并提示“原文引用已失效”，正文撤销后可恢复定位。侧栏保留添加评论时的原文摘录（最多 1000 字符），不自动把评论重新附到其他同名文字。
- 评论及回复沿用文档本机保存；保存失败时保留当前内容，使用“重试保存”后再刷新。刷新、同文档分屏、回收站恢复及完整工作区备份保留评论与引用位置。文档模板的完整快照也保留评论。
- 评论是本地审阅数据，Markdown、HTML、PDF 导出只包含正文；源码改变导致原范围删除时按失效引用处理。暂未接入多人身份、通知或云端实时评论。


## 长文阅读位置

- 自动记住每篇正文的阅读位置；切换标签、关闭后重开或刷新页面，继续显示原来的阅读行。左右分屏分别记录，同一篇文档可以停留在不同位置；手机切换工作台也保留各侧的位置。
- 优先使用文字锚点保持视口位置，图片延迟加载、正文宽度变化和内容高度变化时自动补偿。原位置失效时使用滚动进度或像素位置回退，并限制在文档可滚动范围内；新文档从顶部开始。
- 手动滚动、正文编辑、目录/块链接/脚注/评论定位及页内查找可以接管位置，避免被旧阅读位置拉回。Markdown 源码、弹窗和输入法组合期间不进行正文位置补偿。
- 阅读位置仅保存在当前浏览器的本机偏好中，按工作区、文档、左右侧区分，最多保留最近 1000 条；不写入正文、文档历史、模板或工作区备份，不跨设备同步。保存失败会提示，可从文档选项“重试保存阅读位置”；正文保存不受影响。


## 音频／视频附件播放

- 通过“添加附件”、附件斜杠菜单或拖入文件上传音频、视频，正文自动显示播放器，保留文件名、大小和下载。继续使用本地附件存储及单文件 20 MB 限制，无需联网播放本地文件。
- 使用浏览器原生控件播放／暂停、拖动进度、调整音量，视频支持原生全屏；附件下方可选 0.5×、0.75×、1×、1.25×、1.5×、2×，并提供视频全屏按钮。手机视频在页内播放，窄屏控件换行。
- 文件 MIME 或常见扩展识别音视频，WAV/FLAC/带 ID3 的 MP3 可从文件头识别。实际格式及编解码支持由浏览器决定；损坏或不支持时显示提示和“重试播放”，仍可下载原文件。文件缺失使用既有附件重试和工作区备份恢复。
- 不自动播放；播放另一处媒体会暂停原播放器，包括左右分屏。切换到源码、关闭／切换文档、删除播放器或离开页面停止播放，销毁时释放本地文件 URL。刷新及重开从暂停状态开始，播放进度、音量与倍速不写入文档或备份。
- Markdown 保持附件链接格式，完整工作区备份和文档模板仍包含原始文件；静态嵌入预览及 HTML/PDF 导出沿用附件名称／下载链接，完整播放请打开原文档。

## 主题外观

- 侧栏“外观设置”提供浅色、深色和跟随系统，默认跟随系统。选择后即时预览；保存后刷新保留，取消或关闭弹窗恢复打开前的设置。
- 同一浏览器内所有工作区共用外观；跟随系统时实时响应设备配色变化，保存后其他打开的标签页同步。存储失败可重试或取消恢复。
- 正文、代码、表格、公式、Mermaid、侧栏、弹窗、白板背景与网格、原生表单和媒体控件统一适配。图形和笔记已有填充/文字颜色保留，PDF 页面及 HTML/PDF 导出保留浅色文档配色。
- 外观属于本机偏好，不写入文档、历史、模板或工作区备份。

## 日记／日历式笔记

- 侧栏“今日日记”打开当前工作区当天的日记，没有时按日常记录模板创建。同一天重复打开复用原文档，改标题也不会改变日期归属。日期按设备本地日历计算。
- “日历笔记”浏览月份、跳转日期、回到今天；日期下方标记“记录”或“回收”。支持方向键、Home/End、PageUp/PageDown 选择日期。新建可选择日常记录（记录／待办／回顾）或空白正文，模板只应用于新文档。
- 回收日记会提示“恢复并打开日记”，保留原 ID 和内容；彻底删除后可为该日期重新创建。日记仍是普通可编辑文档，支持白板、附件、标签、收藏、集合、搜索和导出，日期也参与全文检索。
- 完整工作区备份保留日记日期与回收状态，恢复到新工作区后继续按日期复用；各工作区的同日期日记独立。普通 Markdown 导出保留正文，日期归属使用完整工作区备份迁移。
- 命令面板提供“打开今日日记”和“打开日历笔记”；日历适配手机及浅色／深色外观，创建失败可重试。

## 网页剪藏

- 工作区选项中的“网页剪藏”，或命令面板搜索“网页剪藏”，输入公开 HTTP/HTTPS 网页网址后读取。提取标题、正文、标题层级、列表、引用、代码、表格、链接和图片；预览可修改标题和 Markdown，选择目标文件夹与已有标签，再保存为普通文档。
- 剪藏正文末尾保留来源链接及时间。相同来源（包括原请求及跳转后的网址，忽略片段）提示打开已有文档或显式创建副本；在回收站的原文档提示打开回收站。不会覆盖原文档。完整备份保留来源、标签及本地图片，恢复后继续检测重复。
- 图片默认保留远程链接；选择“下载到本机”后可离线查看并随备份迁移。最多 30 张、每张 20 MB、总计 50 MB，仅 PNG/JPEG/GIF/WebP。全部图片下载成功后再创建文档，失败或停止清理本次写入的图片，可切回远程链接重试。预览不会加载远程图片。
- `yarn dev` 以及 `yarn build` 后的 `yarn preview` 提供本机 `/api/clipper` 读取接口，解决浏览器跨域读取限制；仅接受同源本地请求，校验公开地址和每次跳转，拒绝内网／本机地址及非标准端口，不发送浏览器登录凭据。HTML 上限 3 MB，服务器读取超时 15 秒，最多 5 次跳转。
- 纯静态部署没有该接口，可填写原网址并上传保存的 HTML 文件导入（上限 3 MB）；需要登录、动态渲染或限制抓取的网页也使用此入口。上传的 HTML 仍会清除脚本及危险内容，资源地址按填写的网址解析；浏览器保存的本地资源目录不自动上传，离线资源可在文档中另行添加。此批为应用内剪藏，浏览器扩展另行实现。

## 文档悬浮预览

- 桌面悬停正文中的 `@` 文档提及、内部文档链接或双向链接行，延迟显示标题与只读正文摘要；鼠标移入预览可继续查看，本地图片直接读取附件，远程图片以文字占位。预览中的嵌套文档引用只显示，不再次打开浮层。
- 点击“打开文档”沿用文档跳转，点击“另一侧打开”在同工作区另一分屏查看。跨工作区可读取摘要并打开原工作区，另一侧按钮暂不可用。桌面原链接直接点击仍按原方式跳转。
- 链接聚焦后按 `Alt+Enter` 显式打开预览，`Esc` 或关闭按钮收起并恢复触发项焦点；关闭后不会因焦点仍停在链接上自动重开。Tab 可离开预览，预览不锁定页面焦点。
- 手机或触摸设备点击引用先打开预览，再选择打开位置；手机使用底部面板，点击外部或关闭按钮收起，滚动页面时保留显式打开的面板。桌面悬停浮层在滚动／窗口调整时关闭；切换文档、工作区、编辑模式或活动分屏也会关闭。
- 空白文档、已删除目标、读取中及读取失败分别显示提示；失败可重试。打开的摘要响应标题和正文变化。预览不写入文档、历史、备份或阅读位置，关闭释放本次预览使用的图片 URL 与监听。

## 导航历史

- 工作台工具栏提供“后退”“前进”和“导航历史”，快捷键 `Alt+←`／`Alt+→` 操作当前侧的文档历史。命令面板也提供导航后退、前进和打开导航历史。
- 左右分屏各自记录最近 100 条位置：文档、页面／白板模式，以及通过文档／画框链接跳转的画框 ID。连续访问同一位置不重复记录，后退后打开新位置会清除前进分支；普通画布平移、缩放和文字编辑不产生导航记录。
- 导航面板显示当前侧的记录、模式和当前位置，点击可回到该位置。已关闭标签可通过历史重新打开；回收／删除文档会从历史清理，恢复文档后新的访问重新记录。合并分屏时左侧沿用合并前活动侧的历史，右侧历史清空。
- 历史与工作台布局一起保存到本机，保存完成后刷新保留，工作区之间独立；不包含在工作区内容备份中，也不进入正文撤销历史。存储异常沿用工作区保存提示与重试。
- 弹窗打开或输入法组字期间不处理导航快捷键；快捷键优先于编辑器和白板的普通方向键操作。导航历史使用应用内记录，浏览器地址栏的原生后退／前进仍沿用浏览器自己的页面历史。

## 正文块拖拽重排

页面编辑模式中，桌面悬停正文块左侧显示手柄；手机点选正文后显示。拖动手柄到落点线处松手完成移动，长文靠近滚动区域边缘时自动滚动。点击手柄可使用「上移／下移」，正文光标或手柄获得焦点时可按 `Ctrl/⌘+Alt+↑/↓` 重排；在首尾禁用对应菜单操作。

连续跨块选区可整体移动。以正文顶层结构为单位，列表（含嵌套和待办）、引用、标注框、代码和表格保持完整，图片与附件所在段落一起移动。同一编辑器内重排，松手前不写入正文，Escape、越界、指针取消或拖动期间正文变化取消移动。每次重排可一次撤销／重做，复用本地保存、Markdown 导出和备份，并重建有效评论的位置锚点；跨重排边界变为不连续范围的引用标记失效，保留评论并支持撤销恢复。源码、非活动分屏、弹窗和输入法组合期间不执行重排。

## 项目 SQLite 数据库

通过 `corepack yarn dev` 或 `corepack yarn preview` 启动，存储 API 与页面由同一本地服务提供。正式数据库固定在项目根目录 `data/mydoc.sqlite`，不依赖启动命令的工作目录；正文／白板／评论、工作区与界面配置、主题／阅读位置和本地附件字节均写入此文件。Yjs 增量保留为二进制 BLOB，附件使用独立表，浏览器只缓存当前编辑状态。

采用 WAL、FULL 同步及写事务，成功提交后才显示保存成功。服务不可用时显示错误并支持重试，不回退到浏览器持久化；纯静态托管不能独立提供数据库服务。不同浏览器和访问地址连接同一服务时读取同一个数据库；跨客户端的实时内存同步仍属后续协作能力，已提交内容可刷新读取。

服务启动时检查 SQLite `PRAGMA user_version`：未初始化（版本 0）时，在单个事务内创建空表并写入版本 1；已初始化时直接跳过建表，不以是否存在文档判断，也不清空或重新填充数据。初始化失败回滚，修复后重启可重试；数据库版本高于程序时拒绝启动，避免覆盖较新结构。首次不写入示例文档、附件或个人偏好，也不自动导入浏览器旧数据；需要旧内容时通过工作区备份手动导入。

SQLite 运行时可能产生同目录 `.sqlite-wal` 和 `.sqlite-shm` 文件。需要直接复制数据库时，先正常停止服务，再复制 `mydoc.sqlite`；运行期间可使用现有工作区 JSON 备份功能。数据库文件已加入 Git 忽略规则，构建和测试不删除正式数据。浏览器测试使用独立 `data/e2e.sqlite` 与每条测试独立 scope，`MYDOC_DB_PATH` 可为本地服务显式指定其他数据库路径。

分发或复制项目给其他使用者时不要携带 `data/*.sqlite`、`data/*.sqlite-wal`、`data/*.sqlite-shm`，这些运行数据已被 Git 忽略。仅复制源代码，新使用者首次启动会创建自己的空数据库。同一个服务连接同一个数据库，当前尚无多账号数据隔离。

## macOS / Windows 桌面基础

```sh
corepack yarn desktop:dev        # 构建并打开桌面应用，无需另启 Vite
corepack yarn desktop:start      # 使用已构建的应用
corepack yarn desktop:build      # 源码改动后重新构建 Web 页面与 Electron
corepack yarn test:desktop       # 先 desktop:build，再运行真实 Electron 测试
```

**本机打包优先复用已安装的 Electron**，避免 electron-builder 再次从网络获取运行时。以下命令均在项目根目录执行；首次安装后若缺少 `node_modules/electron/dist`，先执行 `node node_modules/electron/install.js`，完成一次运行时下载。

macOS（终端 / zsh，生成本机架构 DMG 和 ZIP）：

```sh
corepack yarn desktop:build
corepack yarn workspace @mydoc/desktop dist:mac --config.electronDist="$PWD/node_modules/electron/dist" --publish never
```

Windows x64（PowerShell，生成 NSIS EXE）：

```powershell
corepack yarn desktop:build
$mydocElectronRuntime = (Resolve-Path "node_modules/electron/dist").Path
corepack yarn workspace @mydoc/desktop dist:win --config.electronDist="$mydocElectronRuntime" --publish never
```

仅重新打包、源码未改动时可跳过 `desktop:build`。本地 Electron 必须与目标平台、CPU 架构及项目 Electron 版本一致；**不要把 Mac 运行时用于 Windows，或把 arm64 运行时用于 x64／双架构包**。双架构、跨平台和下载排查见 [桌面打包说明](docs/桌面打包.md)。原有 `desktop:dist:mac` / `desktop:dist:win` / `desktop:pack` 简写仍可用，但会重新构建并采用构建器默认运行时下载／缓存流程，不是上述复用方式。

桌面版复用全部现有编辑器、白板、主题和工作台。SQLite 在主进程中运行，渲染进程通过 preload 白名单 IPC 访问；启用 contextIsolation、sandbox，关闭 nodeIntegration。应用内页面由仅监听回环地址、随机端口的内部服务加载，静态资源需要会话认证，数据库接口需要主进程专用令牌，无需开放外部服务。

源码开发运行沿用项目 `data/mydoc.sqlite`。安装后的应用使用当前用户的 `userData/data/mydoc.sqlite`：macOS 一般为 `~/Library/Application Support/MyDoc/data/mydoc.sqlite`，Windows 一般为 `%APPDATA%/MyDoc/data/mydoc.sqlite`。可从「文件 → 打开数据目录」查看实际位置。首次只初始化空表，重启跳过，不携带开发数据库，也不自动导入浏览器数据。安装后需要原 Web 内容时，先导出工作区备份再手动导入。

关闭／退出／重新载入前等待文档、工作区和阅读位置保存；附件上传、导入或保存失败时保留窗口并提示。macOS 关闭窗口后应用保留，可从 Dock 重开；Windows 关闭最后窗口即退出。菜单提供编辑、缩放、全屏和数据目录入口，网页外链在系统浏览器打开。

构建产物在 `release/desktop/`，数据库不包含在安装包中。已提供 `.github/workflows/desktop.yml` 在 macOS / Windows 分别运行真实桌面测试并打包。当前打包为未签名开发版本；正式分发所需的 Apple 签名／公证与 Windows 签名证书、自动更新、深链及系统文件关联另列后续任务。跨平台配置不代表已在本机验证 Windows 运行。

macOS 双架构构建由 CI 或《桌面打包说明》中的独立命令执行，按架构下载／缓存运行时，不使用单架构的本地 `electronDist`。首次下载和安装包压缩仍可能耗时；安装包是否生成以命令成功退出为准。
